# 在线书教学内容与实操完善计划

本计划采用已确认的 12 章结构，以普通 Windows 电脑为起点。学生先完成文件检查、结构查看、小规模 CPU 对接和短模拟，再学习结果分析。GPU 筛选、完整模型推理和蛋白设计生成列为进阶任务。实际完成状态单列在[实施记录](在线书完善实施记录-2026-10-02.md)，不以网页存在或链接通过代替操作验证。

## 使用材料与当前问题

备课参照本地 `08_实战教程/03_html_tutorial/完整教程_第1-8章_单文件.html`、两版讲义合订本和操作包，同时读取根大纲、12 章大纲及正文。HTML 实测 151 个 STEP；合订本分别为 939 和 1199 页。旧统计只作历史记录，本次采用实际文件核查数。

原正文和发布层均有 12 章，线上章节能够访问。但部分练习缺少输入、绘图脚本或配置，脚本参数也存在不一致。更新要让学生从公开下载文件独立完成任务。第 7–10 章和第 12 章另补官方文档、公开示例与论文来源，不再把在线书摘要作为扩写证据。

## 项目统一规则

教材正文以概念解释、实际操作和案例分析为主。方法适用范围与结果解释默认集中在每章章末，概括一次。各节不重复通用的不确定表述。通过参数对照、失败案例和修改后重跑，让学生观察差异并归纳。影响操作的输入条件、文件用途、单位和指标定义在相应步骤讲清楚。作者写作前核查事实、术语和来源，直接修正错误。

录播视频、课程 PPT、课程讲义 PDF，以及直接得到的截图、裁剪页、嵌入图片、转制 HTML 和逐页提取全文均留在本地。公开教材使用独立编写的文字、重新制作的图示和来源清楚的练习数据。`06_原始学习素材/` 与 `08_实战教程/` 不进入 GitHub 或网页资源目录。

每章至少有一项基础任务和一次对照练习。先用中文说明操作目的，再给命令，接着说明输出与检查方法。章节组织允许不同，不要求每节套用同一模板。

## 逐章安排

| 章 | 基础任务与案例 | 对照练习 | 学生交付 |
|---|---|---|---|
| 1 环境与文件 | 显示扩展名、打开终端、建目录、交互输入后保存短脚本 | 改错路径并恢复 | 目录、环境记录、检查表 |
| 2 结构可视化 | `3HTB/JZ4` 下载、认链、定位配体、邻近残基、测距、保存 | 改选择半径或原子选择 | 会话、整体图、口袋图 |
| 3 结构与体系准备 | 接续 `3HTB`，填写组分表、拆分、选 altloc、检查键与氢 | 比较处理前后组分和坐标 | 准备文件和组分记录 |
| 4 对接与筛选 | CPU Vina 重对接，再运行 3 个分子 | 盒子偏移、多个 pose；`1IEP/imatinib` 进阶 | 输出、日志、RMSD 和结果表 |
| 5 分子动力学 | `1AKI` 完成体系准备、EM、NVT、NPT、100 ps MD | 比较各阶段日志与参数 | 完整输入、短轨迹、运行记录 |
| 6 轨迹分析 | 下载教师独立生成的轨迹与 XVG，做 PBC、RMSD、RMSF、Rg | Cα/主链选择或分析窗口变化 | 图、摘要、代表构象 |
| 7 自由能 | 阅读真实公开 MM/GBSA 数据、组号和设置 | 全窗口与后半窗口比较 | 均值、分解结果和设置记录 |
| 8 AI 亲和力 | 公共非共价输入、字段检查、结果解析 | 缺字段、同批候选比较 | YAML、解析表和比较表 |
| 9 设计基础 | 官方 RFD3 输出、JSON 长度修改、链统计 | 100 改 80；输入文件名错误 | 配置与骨架记录 |
| 10 设计任务 | PDL1 骨架、CPU ProteinMPNN 序列、回折叠输入 | 两条真实序列对照，缺输出检查 | 候选表和后续任务 |
| 11 AI 编程 | 手工跑通第 4 章后，让 Agent 编写批处理 | 路径错误、漏输出、恢复失败条目 | 脚本、日志、人工复核 |
| 12 项目工作台 | 筛选、结构动态、binder 三条路线 | 对照填好的项目卡修订自己的卡 | 问题、步骤、产物、下一步实验 |

`3HTB/JZ4`、`1AKI` 采用 RCSB 公开结构。Vina、GROMACS、Boltz、Foundry 和 ProteinMPNN 采用官方说明与固定来源。为提高基础任务可完成性，高成本计算允许使用来源明确的官方真实结果；本项目独立重算与官方结果必须分别记录。`3HTB/JZ4` 的 MM/PBSA 独立复算仍是独立交付项，不能用其他体系结果填充。

## 实施次序

1. 先更新 `AGENTs.md`、`CLAUDE.md` 和大纲/正文提示词，修复缺文件及命令接口，保留已有修改。
2. 完成第 1–4 章连续路线；以实际运行核对输入、版本、命令、输出和恢复方法。
3. 完成第 5–8 章输入、真实轨迹、分析与结果包；区分实际输出和字段构造样例。
4. 完成第 9–12 章设计材料、批处理练习和项目卡。
5. 依据 `chapters/public_assets.tsv` 审核资源，生成发布层；完成严格构建和浏览器检查后提交 GitHub，再核对线上新增内容和下载。

每轮先更新章节大纲，再修改正文，最后同步发布。逐章记录“正文修订、资源齐备、实跑通过、本地构建、线上核对”五项状态。未执行的计算列出具体输入、所需环境和下一项检查，不标为完成。

## 验收

- 在新目录中取得公开资源，不依赖作者素材目录、付费账户或 GPU，完成各章基础任务。
- 命令与脚本接口一致；输出可核对；失败练习有恢复步骤。
- 结构查看、CPU 对接、小批量任务与短 MD 保留真实日志；解析与设计阅读任务使用公开文件。
- 每章至少一项基础任务和一次对照，通用方法范围只在章末总结一次。
- 正文与发布层一致；下载、搜索、标签页、流程图和手机阅读实际检查。
- GitHub 提交和线上发布均有可核查记录；作者材料留在本地。
