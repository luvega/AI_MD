# 第 1 章 Linux、计算环境与生化文件基础

## 本章问题与读者任务

区分当前工作目录与 PATH 程序搜索目录列表，帮助学生判断已安装程序为何仍找不到。

第 1 章下载包只含本章资源；3HTB 在 1.3 从 RCSB 下载，不提前要求存在第 3 章目录。已有第 3 章数据的学生可选用本地副本。

让没有终端经验的学生在 Windows 建立课程目录，区分 PowerShell 和 WSL，独立运行短脚本并交出文件清单与环境记录。Linux 必需计算从第 5 章起统一使用 WSL2；第 1–4 章基础路线使用 Windows CPU。

正文先说明动作，再给命令和核对办法。通用解释集中在章末，输入假设和指标定义写在对应步骤。课程录播、PPT、讲义及直接转制文件只作本地备课材料；公开资源采用独立文字、原创图示、官方公开数据和实际计算记录。软件未执行的项目如实注明。
