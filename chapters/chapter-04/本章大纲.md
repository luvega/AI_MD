# 第 4 章 分子对接与虚拟筛选

## 本章问题与读者任务

开头用搜索空间、候选姿势与评分函数解释对接；定义平移、转动、可旋转键、刚性受体及本协议的低分排序方向。

让学生完成 CPU Vina 重对接、检查晶体参考 RMSD，并把同一受体扩展到 JZ4/IPH/BNZ 三分子批次。偏移盒子作为对照，让学生从输出坐标观察搜索范围的影响。

## 资源与实际验证

提供 run_vina_case.py；Vina 1.2.7 Windows 官方程序实际 CPU 运行，cpu=2、seed=20261002、exhaustiveness=16、num_modes=9。三分子结果、命令、日志、JZ4 pose SDF 与 RMSD JSON 均保留。JZ4 首位姿势 RMSD 0.4946 Å 是本案例计算结果。PyMOL 图像脚本未在本机执行，坐标叠加图用 RDKit/Matplotlib 生成。
